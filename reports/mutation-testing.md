# Звіт з мутаційного тестування

Я налаштував Stryker (`stryker.conf.json`), щоб зробити мутаційне тестування для `src/stats-model.js`. Stryker використовує ті самі тести, що й Vitest (unit + integration + e2e), і має згенерувати HTML-звіт у `.stryker-tmp/reports`.

У цьому середовищі мутаційні тести я не зміг запустити, бо npm install не проходить — доступ до npm registry заблокований (помилка 403). Якщо запуск буде можливий, тоді потрібно виконати:

```
npm install
npm run mutation
```

Що має вийти після запуску:

- у консолі буде видно прогрес/результат,

- HTML-звіт буде тут: `reports/mutation/html/index.html` (там показано, які мутанти “вбиті/вижили” і загальний mutation score).

Зараз мої тести покривають основні сценарії для StatsModel і перевіряють роботу з DOM через integration та E2E, тому очікую нормальний (високий) mutation score, коли Stryker реально запуститься.
